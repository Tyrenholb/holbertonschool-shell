Welcome to my Shell, init files, variables and expansions folder.
File: 0-alias : Creates an alias.
File: 1-hello_you : Is a script that prints hello (user)
File: 2-path : Adds /action last to PATH.
File: 3-paths : Is a script that counts the number of directories in PATH.
File: 4-global_variables : Lists enviorment variables in the shell.
File: 5-local_variables : Lists all local variables and environment variables, and functions.
File: 6-create_local_variable : Creates a new local variable Named BEST with the Value: School.
File: 7-create_global_variable : Creates a new global variable named :BESt with the value: School.
File: 8-true_knowledge : Prints the result of the addition of 128 with the value stored in the environment variable TRUEKNOWLEDGE, followed by a new line. TRUEKNOWLEDGE = 1209.
File: 9-divide_and_rule : Prints the result of POWER divided by DIVIDE, followed by a new line. POWER =42784 DIVIDE=32.
File: 10-love_exponent_breath : Displays the result of BREATH to the power LOVE. BREATH=4 LOVE=3.
File: 11-binary_to_decimal : Converts a number from base 2 to base 10.
File: 12-combinations : Prints all possible combinations of two letters, except oo.
File: 13-print_float : Prints a number with two decimal places, followed by a new line. The number will be stored in the environment variable NUM.
File: 14-decimal_to_hexadecimal : Converts a number from base 10 to base 16. The number in base 10 is stored in the environment variable DECIMAL. The script should display the number in base 16, followed by a new line.
